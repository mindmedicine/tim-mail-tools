Privacy policy

Tim mail tools is a personal, single-user tool. Its only user is Tim Vandekerckhove, who uses it to read his own Gmail mailboxes from his own computer.

  • It requests read-only access to Gmail.
  • Sign-in tokens and any mail it reads stay on Tim's own computer. Nothing is sent to, stored on, or shared with any server run by this tool.
  • It does not collect data from anyone else, and it is not offered to the public.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
